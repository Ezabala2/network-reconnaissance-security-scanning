# Network Reconnaissance with Nmap, Zenmap & EtherApe

## Overview
This lab used Parrot OS to examine an authorized virtual network containing Windows and Linux hosts. The exercise combined command-line scanning, graphical scanning, and network traffic visualization.

## Tools
- Nmap — network and service discovery
- Zenmap — graphical Nmap interface
- EtherApe — network traffic visualization
- Parrot OS — lab workstation

## Work performed
1. Ran Nmap service/version detection against assigned lab machines.
2. Reviewed discovered hosts, open TCP ports, and reported services.
3. Used Zenmap's Regular Scan profile for a graphical view of scan results.
4. Used EtherApe to visualize traffic and protocols on the lab segment.
