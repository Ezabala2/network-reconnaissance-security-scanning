# PCAP & Wireless Security Analysis

## Overview
This assignment analyzed wireless-security tools and packet-capture evidence in a controlled educational setting.

## Topics documented
- `aireplay-ng` deauthentication flag (`-0` / `--deauth`)
- Packet injection rate option (`-x`)
- Access-point BSSID filtering (`--bssid`)
- Wireless capture and analysis concepts

## Evidence
The `screenshots/` folder includes the first three non-credential screenshots extracted from the submitted assignment. Later pages of the original submission included wireless network identifiers and recovered key material, so they are **not** included in this public-ready package.

## Notes
These screenshots demonstrate command-line option review and lab documentation, not proof of a successful attack. Only conduct wireless security tests with authorization.
